# Stack

```
Application
├── React
├── TypeScript
├── Vite
├── React Router with HashRouter initially
├── Motion for React
├── CSS Modules
└── Custom UI components

Engine and configuration
├── Framework-independent TypeScript engine
├── yaml
├── Zod 4
├── Custom normalization
├── Custom semantic validation
└── Custom graph-analysis algorithms

State and storage
├── React useState/useReducer for UI integration
├── IndexedDB through idb
└── localStorage only for tiny preferences

Testing
├── Vitest
├── React Testing Library
├── fast-check
├── MSW
├── Playwright
└── @axe-core/playwright

Quality
├── ESLint
├── eslint-plugin-jsx-a11y
├── Prettier
└── pnpm
```
